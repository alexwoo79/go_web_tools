# 清理执行总览

## 目的

- 让文档清理、目录整理和历史归档有统一口径
- 让每次整理都能追踪到变更和验证结果

## 阶段定义

- Phase 0：基线建立
- Phase 1：主入口文档与历史说明归档
- Phase 2：脚本与构建口径整理
- Phase 3：配置与权限说明统一
- Phase 4：可选优化与补充归档

## 文档结构

- `docs/cleanup/README.md`：执行规范
- `docs/cleanup/change-log.md`：总台账
- `docs/cleanup/phase-<n>-log.md`：阶段过程记录

## 每阶段最小记录

1. 目标与范围
2. 变更清单
3. 决策与取舍
4. 验证结果
5. 未完成项与下一步

## 归档原则

- 主入口文档保留最新信息
- 一次性修复说明、历史总结、阶段性报告归档到 `docs/archive/`
- 路径和命令示例使用当前仓库实际内容
